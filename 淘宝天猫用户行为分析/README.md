# 淘宝天猫用户行为分析

基于阿里云天池公开的《淘宝用户购物行为数据集》（UserBehavior），对 2017-11-25 ~ 2017-12-03 共 9 天、**1 亿条**用户行为记录做完整分析：流量趋势 → 转化漏斗 → 留存可行性 → 商品与品类结构，并输出一份 HTML 总结报告。

## 数据下载位置

| 项目 | 说明 |
|---|---|
| 数据集主页 | https://tianchi.aliyun.com/dataset/649 |
| 数据集名称 | 淘宝用户购物行为数据集（UserBehavior） |
| 下载方式 | 登录天池账号后点击「下载数据集」，得到 `UserBehavior.csv.zip`（约 906MB） |
| 解压后文件 | `UserBehavior.csv`（约 3.6GB，约 1 亿行，**无表头**） |
| 放置位置 | 本目录下的 `源数据/UserBehavior.csv` |

字段共 5 列，无表头：

| 列 | 字段 | 含义 |
|---|---|---|
| 1 | user_id | 用户 ID（脱敏整数） |
| 2 | item_id | 商品 ID（脱敏整数） |
| 3 | category_id | 品类 ID（脱敏整数） |
| 4 | behavior_type | 行为类型：`pv` 浏览 / `cart` 加购 / `fav` 收藏 / `buy` 购买 |
| 5 | timestamp | 秒级时间戳，**存的是北京时间**（需 +8h 修正，见下文） |

规模：约 98.8 万用户、416 万商品、9,437 个品类。

## 核心结论

- **流量**：日均 PV 996 万、日均 UV 77.4 万；12-02、12-03 两天跳升约 30%（疑似双 12 预热）。
- **时段**：20-22 点占全天浏览的 24%、订单的 21%，是推送与活动上线的黄金窗口。
- **漏斗**：浏览用户 → 加购/收藏 87.3% → 购买 68.3%，意向到购买 78.3%。
- **结构**：375 个品类（占 4%）贡献 80% 流量；416 万商品中 84.6% 从未被购买。
- **留存**：受采集偏差影响不成立，本项目不输出留存与复购结论。

## 三个必须知道的数据坑

1. **时区偏移 8 小时**：`timestamp` 是北京时间戳，按 UTC 直接 `unit='s'` 解析会整体早 8 小时，时段结论会全错。已在「数据处理」中统一 +8h。
2. **越界脏数据**：原始数据混有约 5.5 万条时间戳越界记录（最早 1902 年、最晚 2037 年），不过滤会把「9 天」算成 212 天。已按 2017-11-25 ~ 2017-12-03 过滤，行数 100,150,807 → 100,095,231。
3. **采集窗口偏差**：12-02、12-03 覆盖了全量用户的 98%，前 7 天只有 72%~75%，说明数据是以最后两天为锚点补齐的历史行为。所有跨天指标（留存、复购）都会失真。

因此本数据集适合做**日内节律、行为结构、品类与商品对比、漏斗形状**，不适合做**留存曲线、复购率、长期趋势**。
转化率的绝对值也不能外推真实淘宝（样本经过购买行为筛选）。
